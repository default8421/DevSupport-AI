# 错误码手册

本手册列出平台所有标准错误码，包含含义、常见原因与处理步骤。诊断时请结合 request_id 查询调用日志确认实际错误码。

## AUTH_KEY_EXPIRED（HTTP 401）

含义：API Key 已过期。
原因：请求使用的 API Key 已超过有效期。
处理：1) 登录控制台查看 Key 状态与过期时间；2) 重新生成 API Key；3) 更新服务端配置后重试。

## AUTH_KEY_INVALID（HTTP 401）

含义：API Key 无效。
原因：API Key 不存在、被禁用或格式错误。
处理：1) 核对 Key 是否复制完整；2) 确认 Key 未被禁用；3) 使用控制台有效 Key 重试。

## SIGN_INVALID（HTTP 401）

含义：签名错误。
原因：请求签名与服务端计算不一致，常见于参数排序、时间戳或密钥错误。
处理：1) 按文档对参数字典序排序拼接；2) 确认使用正确 Secret；3) 校验时间戳在 5 分钟内；4) 重新计算签名。

## PERMISSION_DENIED（HTTP 403）

含义：权限不足。
原因：当前应用无该接口或资源的访问权限。
处理：1) 确认应用已开通该 API 产品；2) 联系管理员授权；3) 重试。

## PRODUCT_NOT_ENABLED（HTTP 403）

含义：接口未开通。
原因：该 API 产品尚未为应用开通。
处理：1) 控制台开通对应 API 产品；2) 等待生效后重试。

## IP_NOT_ALLOWED（HTTP 403）

含义：IP 不在白名单。
原因：请求来源 IP 不在应用配置的白名单内。
处理：1) 控制台将服务器出口 IP 加入白名单；2) 等待生效后重试。

## NOT_FOUND（HTTP 404）

含义：接口不存在。
原因：请求路径错误或接口已下线。
处理：1) 核对接口路径与版本；2) 参考最新文档。

## REQUEST_TIMEOUT（HTTP 408）

含义：请求超时。
原因：请求处理超时，可能为网络或上游慢。
处理：1) 增大客户端超时时间；2) 重试；3) 持续出现请提工单。

## RATE_LIMIT_EXCEEDED（HTTP 429）

含义：QPS 超限。
原因：单位时间请求数超过套餐 QPS 限制。
处理：1) 客户端做本地限速；2) 采用指数退避重试；3) 错峰调用；4) 如需更高并发请升级套餐。

## QUOTA_EXCEEDED（HTTP 429）

含义：调用量超额。
原因：本月调用量已超出套餐配额。
处理：1) 查看本月用量；2) 升级套餐或购买加量包；3) 次月自动恢复。

## INTERNAL_ERROR（HTTP 500）

含义：服务端错误。
原因：服务端内部异常。
处理：1) 稍后重试；2) 记录 request_id；3) 持续出现请提工单。

## PARAM_MISSING（HTTP 400）

含义：参数缺失。
原因：缺少必填参数。
处理：1) 对照文档补齐必填参数；2) 重试。

## PARAM_INVALID（HTTP 400）

含义：参数格式错误。
原因：参数类型或格式不符合要求。
处理：1) 核对参数类型与格式；2) 修正后重试。

## BALANCE_NOT_ENOUGH（HTTP 402）

含义：余额不足。
原因：账户余额不足以完成本次计费调用。
处理：1) 控制台充值；2) 充值后重试。

## DATA_EMPTY（HTTP 200）

含义：查询结果为空。
原因：请求成功但未命中数据，可能为参数不匹配或数据未覆盖。
处理：1) 核对查询参数；2) 确认数据覆盖范围；3) 如确认应有数据请提数据质量工单。

## DATA_INCONSISTENT（HTTP 200）

含义：数据不一致。
原因：返回数据与预期来源存在差异，可能为更新延迟。
处理：1) 查看数据更新时间；2) 提供对比样例提数据质量工单。
